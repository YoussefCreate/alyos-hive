# Contributing

Thanks for helping the hive grow.

1. Fork the repo and create a branch.
2. Keep the core free of third-party packages: standard library only.
3. Add or update a test in `tests/` and run `python -m unittest discover -s tests`.
4. Open a pull request saying what changed and why.

Agents must keep the human approval gate. Pull requests that publish, send or sell anything without an explicit human step will not be merged.
