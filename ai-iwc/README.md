# AI-IWC

AI-IWC is the earlier local agent system (Python and Ollama) built in May 2026, with an operational core (v0.1) and Trend, Research and RSS inspiration agents (v0.2).

Its code is being merged here. The plan is to turn its agents into extra gatherers that feed the hive's `signals` table, so everything flows through the same Scout → Analyst → Builder → human approval path.
