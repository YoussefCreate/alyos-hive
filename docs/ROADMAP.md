# Roadmap

## v0.1 (now)
- Gather, Scout, Analyst and Builder agents
- Ollama, Anthropic and mock backends, standard library only
- SQLite store, approval queue, markdown report
- Claude skills mirroring the three roles

## v0.2
- Bring in the AI-IWC agents (Trend, Research, RSS inspiration) as extra gatherers
- `hive sales` command to log listings and sales against approved offers, so the Analyst can learn which offer types sell
- Feed packs: ready-made feed lists per niche

## v0.3
- Simple local web dashboard to review offers in the browser
- Builder writes the full deliverable (guide, template, workflow file) for approved kits
- Export approved offers as CSV for bulk listing

## Later
- Multi-model "council": two models score each opportunity and a third settles disagreements
- Plugin interface so others can add their own workers
